# Contract: visible copy and accessible names (spec 002)

| Element | Text / accessible name |
| --- | --- |
| Site name (header link to `/`) | DeskDrop |
| Nav links | Shop · Wishlist · Orders · Account |
| Wishlist count (header link to `/wishlist`) | Wishlist (<n>) |
| Bag link | Bag (<n>) |
| Mobile menu button | Menu (`aria-expanded`, controls the nav) |
| Home heading (h1) | DeskDrop |
| Search input label | Search products |
| Category group label | Category; options as in the catalog |
| Stock toggle | In stock only |
| Sort select label | Sort by; options Featured · Price: low to high · Price: high to low · Top rated |
| Result count (live region, polite) | <n> products (1 product) |
| Empty results | No products match your filters. + button Clear filters |
| Quick-add button | Add to bag (accessible name "Add <product name> to bag"); out of stock: Sold out (disabled) |
| Wishlist toggle | `aria-pressed`; name "Save <product name> to wishlist" |
| Footer credit | Built with CodeRabbit (logotype `alt="CodeRabbit"`) |
| Not-found heading | Page not found + link Back to the shop |
